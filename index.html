Add this address to Kodi

https://mooseca.github.io/repository.mooseca/

Install

  1. Settings → System → Add-ons: turn on Unknown sources.
  2. Settings → File manager → Add source: choose <None>, enter the address above and name it mooseca.
  3. Settings → Add-ons → Install from zip file → mooseca: pick repository.mooseca-1.0.1.zip.
  4. Install from repository → Mooseca Repository: pick an add-on and Install.

Kodi then keeps the add-ons up to date by itself. Or download the repository zip and use Install from zip file on it:
repository.mooseca-1.0.1.zip
